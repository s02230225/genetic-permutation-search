# Генетический поиск перестановки признаков

**Python · NumPy · оптимизация**

Поиск перестановки столбцов матрицы для минимизации нелинейной целевой функции. Используются турнирный отбор, сохраняющее перестановку скрещивание, адаптивная мутация, элитизм и локальный поиск.

```bash
python3 optimizer.py --seed 17 --generations 30 --seconds 2
python3 optimizer.py --data matrix.csv --population 40 --generations 100 --seconds 5
python3 -m pytest -q
```

CSV содержит только числа, без заголовка. Без файла создаётся маленький искусственный пример. Результат содержит перестановку, значение функции, историю лучшего решения и seed. Необязательный --output пишет новый JSON-файл.

Случайность управляется локальным генератором; поиск ограничивается числом поколений и временем. Точное перечисление `exact_solution` доступно для матриц до восьми столбцов и используется как эталон на малых примерах. При временном лимите число поколений может зависеть от скорости машины; повторяемость сравнивается при одинаковом числе завершённых поколений.
