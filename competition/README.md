# Задача AI Masters 2025: оптимизация перестановки

Соревновательный ноутбук с целевой функцией, примерами вычисления и подготовкой CSV
в формате Public/Private. Требуется выбрать порядок 100 столбцов матрицы, минимизирующий
нелинейную целевую функцию. Исходная матрица `X_aim.csv` находится рядом с ноутбуком.

Реализация генетического и локального поиска вынесена в `../optimizer.py`:

```bash
python3 ../optimizer.py --data X_aim.csv --seed 17 --generations 100 --seconds 5
```

Для ноутбука нужны NumPy, pandas и Jupyter. Ячейка экспорта записывает `sol.csv`
в текущем рабочем каталоге. Алгоритм поиска и соревновательный ноутбук представляют
разные части одного проекта.
